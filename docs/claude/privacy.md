### Privacy and legal (Nov 2026)

`lib/privacyRegion.ts` is the one place for location- and age-based privacy rules. Google Analytics runs only when allowed: `ANALYTICS_INIT_SCRIPT` (inline in `app/layout.tsx` `<head>`, before gtag) sets GA's kill switch `window["ga-disable-<id>"]`, and `components/AnalyticsConsent.tsx` (root layout) keeps it current, learns the country once from `/api/geo` (cookie `tt-cc`) and shows the cookie banner in the EEA, UK and Switzerland until the visitor chooses (`tt-consent`; `/privacy` has a button that reopens it for anyone). An unknown country (`ZZ`) gets the same opt-in. The first `gtag('config')` in `app/layout.tsx` is skipped while the kill switch is on, because GA drops the page view of a config sent then and a later config does not bring it back; `AnalyticsConsent` sends the config once GA is allowed, so a first-time visitor's page view and its source are kept. GA is always off on children's tests (`CHILD_PATH_PREFIXES`: times tables, KS2, 11+, OC, NSW Selective, NAPLAN Year 7, JNVST, AISSEE, `/c/`) and for any browser with a class or quiz membership; add a new primary or middle-school exam's slug and landing there. A declined choice also stops the anonymous counters (`isTestBrowser()` checks `analyticsDeclined()`). **Vercel Web Analytics** (`components/VercelPageAnalytics.tsx`, root layout, Nov 14 2026): cookieless page views by path, referrer, country and device, for seeing which landings get traffic; never sent from a browser `isInternalBrowser()` flags (test, internal or declined), and `redactPageUrl()` (`lib/pageAnalytics.ts`) drops every query parameter but `utm_*` and blanks class and quiz codes in the path. Only pages people land on are sent (`isTrackedPage()`: dashboards, tests, practice, results, stats, account, class and quiz pages are skipped by whole path segment), to keep Vercel's event count low; every sitemap URL must pass it. It only collects once Web Analytics is enabled on the Vercel project (dashboard, Analytics tab; there is no API switch); the Vercel connector's `aggregate_pageviews` then reads it. The signup email box and the Google sign-in paths use `defaultEmailConsent()`: unticked in the EEA, UK, CH and Canada or when the country is unknown. Settings has Delete account (`components/DeleteAccountSection.tsx`, `/api/account/delete`: users doc, quizzes, classes taught, memberships, assistant play, enrollments, signup origin, OAuth tokens, then the Auth user; payments are kept for tax). Marketing email footers carry `postalFooterLine()` (`lib/emailPostal.ts`, env `EMAIL_POSTAL_ADDRESS`, required by CAN-SPAM). `/privacy` and `/terms` describe what the code does; when a feature collects new data or adds a processor, update `/privacy` and its date.
