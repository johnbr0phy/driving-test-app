- **GMAT** (`/gmat`, landing `/gmat-focus-practice-test`, `[data-theme="gmat"]` dusty rose, region GLOBAL): GMAT Focus Edition, three 45-minute sections, Quantitative Reasoning 21 (problem solving only, arithmetic and algebra, no calculator; optional 10-minute break after it via `breakAfter`), Verbal Reasoning 23 (13 reading comprehension in four shared passages, 10 critical reasoning) and Data Insights 20 with the calculator (7 Data Sufficiency with the five fixed choices, 3 Table Analysis as True/False `matrix`, 4 Graphics Interpretation as `cloze` with the graph given as a pipe table or in words, 3 Two-Part Analysis as `matrix`, one part per row, or classify-each for verbal two-part items, and one 3-item Multi-Source Reasoning set on a shared stimulus). Two fixed (not adaptive) tests, Test 2 held out; 7 drills (`gmatArith`, `gmatAlgebra`, `gmatCR`, `gmatRC`, `gmatDS`, `gmatTables`, `gmatTwoPart`), so the dashboard is 9 steps. Sections scale 60 to 90 with `curve()` (step 1); `gmatTotal()` maps the sum to 205 to 805 in steps of 10, an estimate. Bank `data/v2/gmat/questions.json` (169 original items, prefix `GMAT-`, object form with 13 stimuli) built by its own `tools/gmat/build.py` from `quant.py`, `verbal.py`, `di.py` (items in presentation order; Quant, DS and numeric MSR options use `lockedOrder`). Sources in `tools/gmat/sources.md`.
