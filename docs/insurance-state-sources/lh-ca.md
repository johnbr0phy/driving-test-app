# California Life & Health (LINE=LH, ST=CA): sources (all accessed 2026-10-17)

## Official exam facts

| Fact | Value | Source |
|---|---|---|
| Regulator | California Department of Insurance (CDI) | insurance.ca.gov |
| Vendor | PSI Services LLC (PSI test centers, CDI site in Los Angeles, or PSI online remote proctoring) | 2025 Life and A&H License Examination Objectives; PSI/CDI Candidate Information Bulletin rev. March 2026 |
| Licenses | Life agent (Ins. Code 1626(a)(1)) and Accident and Health or Sickness agent (Ins. Code 1626(a)(2)) are separate license types | 2025 objectives |
| Exams | Life: 75 questions. Accident and Health or Sickness: 75 questions. Combined "Life, Accident and Health or Sickness": 150 questions | CDI "Examinations: Time Limit and Number of Questions" page; CIB March 2026 time table |
| Time | CDI page: Life 1.5 h, A&H 1.5 h, combined 3 h. CIB March 2026 table: Life 105 min, A&H 105 min, combined 195 min (the bulletin adds time for up to about 10% unscored experimental items) | both pages below |
| Combined exam rule | An applicant for both life and A&H passes one examination covering both (Ins. Code 1676(b)) | Ins. Code 1676 |
| Pass score | 60 percent on every producer exam (70 only for Life and Disability Analyst, adjuster, bail) | CIB March 2026 p.16; CDI exam time page |
| State vs general split | None. California exams are integrated: every outline section mixes general concepts and California Insurance Code objectives | 2025 objectives |
| Prelicensing | 12 hours of study on ethics and the Insurance Code (incl. 1 hour fraud); the 20-hour course now applies to bail and public adjusters | Ins. Code 1749(a); CIB March 2026 |
| Exam validity | License must issue within 12 months of passing | Ins. Code 1676(a); CIB |
