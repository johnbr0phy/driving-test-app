# Texas sales agent exam: sources (all accessed 2026-10-17)

## Official exam facts

| Fact | Value | Source |
|---|---|---|
| Vendor | Pearson VUE | Pearson VUE Texas Real Estate Candidate Handbook #094400, September 2026 (rev08/2026), https://www.pearsonvue.com/content/dam/VUE/vue/en/documents/publications/094400.pdf |
| National portion | 80 scored + 5 pretest = 85 items, 150 minutes | Handbook "Available exams and time allotted" table; outline #094401 (national salesperson outline effective March 1, 2025) |
| Texas state portion | 40 scored + 10 pretest = 50 items, 90 minutes | Handbook table; Texas Sales Agent State Law Content Outline, effective January 1, 2026, in #094401 (01/2026), https://www.pearsonvue.com/content/dam/VUE/vue/en/documents/publications/094401.pdf |
| Total appointment | 125 items, 240 minutes for both portions | Handbook table and "Candidates will be given 240 minutes" |
| Pass score | 70% on each portion: 56 of 80 national, 28 of 40 state | Handbook "Score explanation"; TREC Rule 535.57(c) (at least 70% in each portion for sales agents) |
| Retakes | Retake only the failed portion; three failures require 30 more hours per failed part (60 if both) | Handbook "Retaking the exam"; TREC Rule 535.57(e) |
| Score validity | Each passed part valid one year | TREC Rule 535.57(d); TREC sales agent page |

The state portion was 30 scored items before 2026. The current outline (effective January 1, 2026) says 40, so the form uses 40, not the 30 in the brief.

### Texas state-law outline (sales agent, effective January 1, 2026)
I Commission duties and powers 3; II Licensing 3; III Standards of conduct 9; IV Agency/brokerage 11; V Contracts 9; VI Special topics 5 (community property, homestead, DTPA, wills and estates, landlord-tenant, foreclosure and short sales, recording statutes, mechanic's liens, Veterans Land Board, HOAs, equitable interest). Total 40.

### National outline (salesperson, effective March 1, 2025)
Property 11, ownership/title 9, valuation 11, contracts and agency 16, practice 10, disclosures/environmental 9, financing/settlement 7, math 7. Total 80.

## Chosen form
120 items = 80 national picks (exact national outline weights) + 40 Texas items (exact state outline weights). Mirrors the scored items; pretest items are not modeled.
