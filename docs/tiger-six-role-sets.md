# Six professional-role tiger sets

Eight 512 × 512 RGBA images with transparent backgrounds per exam: firefighter (`ffi`), police (`police`), FAA private pilot (`faapvt`), NASM personal trainer (`nasm`), barber (`barber`) and journeyman electrician (`jelec`).

Each character was generated using the built-in image tool with the established TigerTest style. Seven identity-preserving edits of its happy default retain clothing, pose and tools.

Expressions follow `TIGER_ASSET_PROMPTS.md`: crowned winner, celebrating, happy, confident closed smile, tentative closed smile, neutral flat closed mouth, closed frown, and open worried mouth with three blue sweat drops.

Visual review checked identity, expressions, props and margins. Automated checks cover all eight paths, PNG size/type, distinct files, score boundaries and scoped social-image cache versions. Site branding and unrelated mascots remain unchanged.
