# AZ-900 sources

All 150 items are original, written from Microsoft's public outline and documentation. No item is copied from Microsoft's practice assessment or any other bank.

- **Study guide for Exam AZ-900: Microsoft Azure Fundamentals**, Microsoft Learn, "Skills measured as of July 20, 2026" (page dated 2026-05-31, updated 2026-06-22). https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900
  Skill areas: Describe cloud concepts 25-30%, Describe Azure architecture and services 35-40%, Describe Azure management and governance 30-35%; 11 sub-areas. Passing score 700.
- **Microsoft Certified: Azure Fundamentals** certification page (last updated 2026-07-20): 45 minutes, proctored, interactive components possible, retake after 24 hours for the first retake, price by country. https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/
- Microsoft Learn path "Azure Fundamentals" (modules: Describe cloud computing, benefits, service types, core architectural components, compute and networking, storage, identity/access/security, cost management, governance and compliance, managing and deploying, monitoring tools) for the facts behind each item.
- Azure Storage docs for access tiers (Cool 30, Cold 90, Archive 180 day minimums), redundancy (LRS, ZRS, GRS, GZRS, RA-*), storage account types.
- Management groups docs (six levels of depth below root, 10,000 groups per directory).
