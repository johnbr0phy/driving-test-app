# Property and casualty review, November 27, 2026

These original items were revised against the following primary sources, accessed 2026-11-27. No answer letters changed.

- PCOH-OHMKT-003: [Ohio Revised Code 3905.33(B)(1)](https://codes.ohio.gov/ohio-revised-code/section-3905.33). The example gives the agent eight qualifying insurers. The five-insurer minimum applies in that case.
- PCCA-CAPOL-003: [California Department of Insurance, 2026 residential property notice](https://www.insurance.ca.gov/0200-industry/0050-renew-license/0200-requirements/upload/2026-Notice-Significant-California-Laws-Pertaining-to-Residential-Property-Insurance-Policies-Declared-State-of-Emergency.pdf), Insurance Code section 678(c). The stem asks about personal delivery. The explanation distinguishes service by mail.
- PCMI-MIWC-004: [Michigan Compiled Laws 418.351(1)](https://www.legislature.mi.gov/documents/mcl/pdf/mcl-418-351.pdf). Use the after-tax average weekly wage for the initial calculation and apply the maximum.
- PC-LIA-021, including state copies: [Public Risk Innovation, Solutions, and Management, Introduction to Excess Liability Coverage](https://www.prismrisk.gov/member-services/guidance-and-resource-library/risk-simplified/prism-risk-simplified/introduction-to-excess-liability-coverage/?v=1.2). The risk pool explains how an umbrella can cover a loss outside the underlying form, subject to its retained limit. The alternatives reflect confusion about deductibles, reinstatement and retention.
