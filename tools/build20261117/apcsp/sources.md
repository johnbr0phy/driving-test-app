Every question, passage, data set and code example is original. No official sample, past or commercial question material was used.

## Format
College Board, AP CSP Exam, fetched 2026-11-17.
https://apcentral.collegeboard.org/courses/ap-computer-science-principles/exam
70 MCQs in 120 minutes, 70% of the AP score: 57 standalone single-answer, five reading-passage single-answer and eight choose-two items. Create performance task plus written responses supplies the other 30%. No conversion of our percentage to AP 1–5 is claimed.

## Spec
V2 id apcsp; prefix APCSP; slug /ap-computer-science-principles; landing /ap-computer-science-principles-practice-test. No v1 state code or numeric idBase. Free school exam. Two 70-question, 120-minute MCQ tests; Test 2 held out; 60 additional drill-only items. 200 unique items total. No official pass percentage; practice targets only.
Per-test big-idea counts: Creative Development 8, Data 14, Algorithms and Programming 23, Computer Systems and Networks 9, Impact of Computing 16. These lie within official 10–13%, 17–22%, 30–35%, 11–15%, 21–26% ranges. Pools respectively 24,40,64,26,46. Multiple-select counts per test respectively 1,2,3,1,1. Five passage questions per test in Impact. Shared original passage with distinct questions is intentional.
