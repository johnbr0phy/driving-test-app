# CISSP bank sources

Exam: ISC2 Certified Information Systems Security Professional (CISSP).

- ISC2 CISSP Certification Exam Outline, effective April 15, 2024 (still the live outline in
  October 2026; the 2026 ISC2 outline change was the CCSP, effective August 1, 2026, not the CISSP).
  https://www.isc2.org/certifications/cissp/cissp-certification-exam-outline
  Domain weights: 1 Security and Risk Management 16%, 2 Asset Security 10%, 3 Security Architecture
  and Engineering 13%, 4 Communication and Network Security 13%, 5 Identity and Access Management 13%,
  6 Security Assessment and Testing 12%, 7 Security Operations 13%, 8 Software Development Security 10%.
  All languages (English, Chinese, German, Japanese, Spanish) are CAT since 2024 per ISC2's outline
  page (checked 2026-10-30), which also announces a new outline effective April 15, 2027.
  Exam: CAT, 100 to 150 items, 3 hours, 700 of 1000 to pass. Item types: multiple choice and
  advanced innovative (drag and drop, hotspot).
- ISC2 Code of Ethics (canon order: society, honorable conduct, principals, profession).
- NIST SP 800-37 Rev. 2 (RMF steps), SP 800-88 (clear, purge, destroy; Rev. 2 of Sept 2025 keeps them), SP 800-63B Rev. 4 (Aug 2025,
  passwords), SP 800-137 (continuous monitoring); FIPS 203, 204, 205 (August 2024 post-quantum standards).
- AICPA SOC 1, SOC 2 (Type I and II) and SOC 3 report descriptions.
- OWASP Top 10 and API Security Top 10 (broken object level authorization), for Domain 8.

Mock design: two linear 100-item tests (the CAT minimum) in 120 minutes (the real pace of 150 items
in 180 minutes), no going back, weighted 16/10/13/13/13/12/13/10 per test; 24 drill-only items (3 per
domain). Test 2 is held out of the drills. 224 items. Drag and drop is modelled by 7 order and 7 matrix
items; hotspots are not modelled; the mock is not adaptive. All items are original, written from the
outline topics; none copied from the Security+ bank or any published question bank.

Checked by web search 2026-10-30: secondary sources (reporting ISC2's outline page as of April 2026)
confirm the April 15, 2024 outline, CAT 100 to 150 items and 3 hours. ISC2's own page was not opened
directly; the exam fee is not stated anywhere in this exam's copy.
