# Google Cloud Digital Leader (gcdl) sources

- Cloud Digital Leader Certification exam guide, Google Cloud
  (https://services.google.com/fh/files/misc/cloud_digital_leader_exam_guide_english.pdf), footer
  "launched on August 12, 2026", read 2026-10-30. Sections and weights: 1 Digital Transformation with
  Google Cloud ~18%, 2 Exploring Data Transformation with Google Cloud ~18%, 3 Innovating with Google
  Cloud Artificial Intelligence ~18%, 4 Modernize Infrastructure and Applications with Google Cloud ~18%,
  5 Trust and Security with Google Cloud ~18%, 6 Scaling with Google Cloud Operations ~10%. Subsections
  1.1-1.2, 2.1-2.3, 3.1-3.2, 4.1-4.3, 5.1-5.2, 6.1-6.2; every item's `skill` maps to a bullet there.
- Certification page (https://cloud.google.com/learn/certification/cloud-digital-leader), read
  2026-10-30: 90 minutes, 50-60 multiple choice and multiple select questions, 99 USD, English,
  Japanese, Spanish, Portuguese, French, online or test center, valid 3 years, no prerequisites;
  renewal exam 20 questions in 45 minutes. "As of August 12, the new version of the exam is now live."
  No numeric passing score is published (pass/fail only).
- What changed from the previous guide (weights 17/16/16/17/17/17), per the guide itself and prep-site
  comparisons: agentic AI, generative AI, the AI Hypercomputer and Google's security portfolio (Google
  Threat Intelligence, Security Command Center, Google Security Operations, Model Armor, AI Protection)
  added; sustainability and the Customer Care support-case lifecycle removed; operations cut to 10%.
- Product names as of 2026, checked with web search: Gemini Enterprise Agent Platform is the April 2026
  (Cloud Next '26) successor to Vertex AI, with Vertex AI Studio renamed Agent Studio; Managed Service
  for Apache Spark is the 2026 name for Dataproc (clusters and serverless); Cloud Run functions is the
  2024 name for Cloud Functions; Sensitive Data Protection includes Cloud DLP.

Deliberately avoided (likely to change, or not in the 2026 guide): prices and discount percentages,
SLA numbers, exact storage minimum durations beyond Nearline 30 and Coldline 90 days (in explanations
only), support plan tiers, sustainability and carbon claims, App Engine, Agent Engine/Agent Runtime
and other agent sub-product names beyond those in the guide.

Blueprint per 60-item test (real exam maximum, 90 minutes): transform 11, data 11, AI 11, modernize 10,
security 11, ops 6. One choose-two item per section except ops (5 per test). Drill-only items: 80
(14/14/14/14/14/10). Pools 36/36/36/34/36/22 = 200. All items original; none copied from the AWS,
AZ-900 or other banks.
