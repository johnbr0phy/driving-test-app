# caplumb sources (checked 30 Oct 2026)

Which outline: the CURRENT Red Seal Plumber breakdown on red-seal.ca, which is the 2023 Red Seal
Occupational Standard (RSOS). red-seal.ca shows no newer plumber RSOS or transition date, and
SkilledTradesBC notices confirm plumber IP exams have followed the 2023 RSOS since 25 April 2025.

## The exam
- https://red-seal.ca/eng/trades/plumbers/exam-information.shtml : "This trade's Red Seal exam has 125 questions", four-option multiple choice, one correct answer.
- https://red-seal.ca/eng/trades/plumbers/exam-weightings.shtml : MWA weights A 11% (common occupational skills), B 10% (prepares and assembles tube, tubing and pipe), C 26% (sewers, sewage treatment systems, DWV), D 19% (water service and distribution, incl. private water pressure systems), E 13% (fixtures, appliances, water treatment), F 13% (low-pressure steam and hydronic; task F-16 steam is "not common core", 0%), G 8% (specialized systems: process piping 51%, potable water fire protection 0% not common core, other specialized 49%).
- https://red-seal.ca/eng/resources/exam-prep-guide.shtml : 70% pass mark, 4 hours, one mark per question, reference material (acronym list, formulas, code book information) only where required.
- https://www.red-seal.ca/_conf/assets/custom/docms/plumber/rsos-eng.pdf : the 2023 RSOS itself (task and sub-task scope).
- SkilledTradesBC program notices (https://skilledtradesbc.ca/node/114, plumber notice Feb 2025 and June 2026): exams from 25 Apr 2025 aligned to the 2023 RSOS; candidates in BC receive the National Plumbing Code of Canada 2020 and, from 17 June 2026, a reference booklet with diagrams, acronyms and formulas. Other jurisdictions may differ.
- Ontario trade code 306A = Plumber (Skilled Trades Ontario).

## Code figures used (National Plumbing Code of Canada 2020, confirmed via secondary sources)
- NRC NPC 2020 page: https://nrc.canada.ca/en/certifications-evaluations-standards/codes-canada/codes-canada-publications/national-plumbing-code-canada-2020
- 550 kPa static pressure -> pressure-reducing valve: CIPH NPC 2015 presentation (https://cdn.ymaws.com/www.ciph.com/resource/resmgr/weekly_update/National_Plumbing_Code_2015_.pdf), BC Building Code Appeal Board #1454.
- 38 mm minimum trap seal: NPC 2.2.3.1 (Traps); same 38 mm in the Ontario Building Code mirror, Div. B 7.2.3.1 (reviewer check 30 Oct 2026).
- DWV water test 3 m head for 15 min, air test 35 kPa 15 min: Manitoba ITS plumbing pressure test form, North Dundas plumbing test sheet, TRU BC plumbing apprenticeship text (https://d-drainagesystems-bcplumbingapprl2.pressbooks.tru.ca/chapter/d-4-1-drainage-system-testing-code-requirements/).
- 49°C maximum to showers and bathtubs in residential occupancies: TSASK Plumbing Code 2020 (Saskatchewan's NPC 2020 adoption), Ontario O. Reg. 332/12, BC 2012 plumbing update.
- From trade knowledge, not re-verified against the code text: 3 in minimum drain for a water closet; 1 in 50 slope; air gap 2 x effective opening and at least 25 mm (CSA B64.10 / NPC); 60°C storage for Legionella.

## Trade practice (no single source; standard apprenticeship content)
Copper type colour code (K green, L blue, M red, DWV yellow); NPT 1 in 16 taper; brazing above 450°C; T&P 99°C / 1034 kPa (210°F / 150 psi); boiler relief 207 kPa (30 psi), cold fill about 83 kPa (12 psi); low-pressure steam 103 kPa (15 psi); primary-secondary tees within 4 pipe diameters; condensing below about 54°C return; heat = flow x 4.19 x temperature drop, Q = 500 x gpm x temperature drop; suction lift about 7.5 m; pressure tank pre-charge 14 kPa (2 psi) below cut-in; CSA Z7396.1 medical gas, CSA B64 backflow, CSA B149 gas, CSA W47 welding certification.

Provincial matters are written as "varies": permits and inspections, trench and confined-space limits, septic setbacks, backflow tester certification and test intervals, grey water fixtures, dishwasher air gap vs high loop.

All 200 questions are original. Nothing was copied from Red Seal sample questions, provincial study guides or commercial question banks.
