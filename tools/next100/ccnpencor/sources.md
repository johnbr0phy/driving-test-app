# Cisco CCNP ENCOR (350-401 v1.2) sources

All 224 items are original, written from Cisco's published ENCOR 350-401 v1.2 exam topics, Cisco configuration guides and tech notes, and the IETF RFCs and NIST publications that define the protocols. No item is copied or reworded from Cisco practice questions, Cisco Learning Network quizzes, official cert guide review questions, any prep provider, dump site or other bank. Pages fetched 2026-11-19.

Build: `python3 -I tools/next100/ccnpencor/build.py` (local python3 is 3.9, so the builder carries a `from __future__ import annotations` shim). Lint one domain: `python3 -I tools/next100/ccnpencor/build.py --check encorArch`.

## Outline and format
- **Implementing Cisco Enterprise Network Core Technologies v1.2 (ENCOR 350-401) exam topics**, Cisco, (c) 2025, Cisco Public, fetched 2026-11-19. https://learningcontent.cisco.com/documents/marketing/exam-topics/350-401-ENCORE-v1.2.pdf
  "a 120-minute exam associated with the CCNP and CCIE Enterprise Certifications". Six domains: 1.0 Architecture 15% (2-tier, 3-tier, fabric and cloud design; redundancy, FHRP and SSO; Catalyst SD-WAN control and data planes, benefits and limitations; SD-Access control and data planes; interpret QoS configurations), 2.0 Virtualization 10% (hypervisor type 1 and 2, virtual machines, virtual switching; VRF; GRE and IPsec tunneling; LISP; VXLAN), 3.0 Infrastructure 30% (802.1q trunking, EtherChannels, RSTP, MST, root guard and BPDU guard; EIGRP vs OSPF; OSPFv2/v3 multiple normal areas, summarization, filtering, network types, passive-interface; eBGP between directly connected neighbors, best path selection; policy-based routing; NTP and PTP; NAT/PAT; HSRP and VRRP; multicast: RPF check, PIM SM, IGMP v2/v3, SSM, bidir, MSDP), 4.0 Network Assurance 10% (debugs, conditional debugs, traceroute, ping, SNMP, syslog; Flexible NetFlow; SPAN/RSPAN/ERSPAN; IP SLA; Catalyst Center (formerly DNA Center) traditional and AI-powered workflows; NETCONF and RESTCONF), 5.0 Security 20% (lines and local user authentication; AAA; ACLs; CoPP; REST API security; threat defense, endpoint security, next-generation firewall, TrustSec and MACsec), 6.0 Automation and Artificial Intelligence 15% (Python components and scripts; JSON; YANG; Catalyst Center and SD-WAN Manager APIs; REST response codes; EEM applets; agent vs agentless orchestration).
- **350-401 ENCOR exam page**, Cisco, fetched 2026-11-19. https://www.cisco.com/c/en/us/training-events/training-certifications/exams/current-list/encor-350-401.html
  120 minutes; English and Japanese; US$400 (not used in any item). Cisco publishes no item count or passing score; the page names no newer version.
- The v1.2 topics took effect March 19, 2026 (v1.1 last test date March 18, 2026), per two training providers' notices (guides say; Cisco's own announcement could not be found). v1.2 removed the wireless topics of v1.1 and renamed products (Catalyst Center, Catalyst SD-WAN). No v2.0 or other dated change was announced as of 2026-11-19, so no freshness event is recorded.
- Cisco publishes no item count; candidates and guides report about 90 to 110 items, so a practice test here is 100 items in 120 minutes, answered in order (Cisco exams move forward only).
