# Glossary for `deeinb` (German, written natively)

Register: questions and explanations in neutral third person, "Sie" in scenarios; landing and UI
copy in "du" (consumer-app norm, as detheorie). German typography: „ “ quotes, thousands point
(1.000), dates "9. November 1989". No em-dashes.
