# Glossary for `demotorrad` (German, written natively)

Same register and typography as `detheorie`: questions and explanations in "Sie", landing and UI
copy in "du"; „ “ quotes; decimal comma (0,2 kW/kg, 1,1 ‰); thousands point (100.000 m); km/h,
kW, cm³. No em-dashes. Signs are described in words with their StVO number once.
