# Glossary for `detheorie` (German, written natively)

Register: questions and explanations in "Sie" like the official catalogue; landing and UI copy in
"du" (consumer-app norm, LANGUAGES.md 2.1). German typography: „ “ quotes, decimal comma (0,5 ‰,
1,6 mm, 3,5 ng/ml), thousands point (3.500 kg), km/h, m. No em-dashes.

Signs: always described in words with their StVO number once, "Zeichen 205 (Vorfahrt gewähren)".
Where the question asks what a sign means, only the shape, colour and number are given.
