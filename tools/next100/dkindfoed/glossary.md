# Glossary for `dkindfoed` (Danish, written natively)

Register: questions and explanations neutral and impersonal ("man", "en vælger", "Hvad gælder ..."),
like the real test; landing and dashboard copy in "du" (consumer-app norm). Danish typography:
» « for quoted titles and sayings (no straight double quotes), decimal comma, thousands point
(7.000), ordinal kings as "Christian 4.", dates "5. juni 1849". No em-dashes or en-dashes.
Never name a current officeholder (monarch, statsminister, ministers): ask about institutions.
