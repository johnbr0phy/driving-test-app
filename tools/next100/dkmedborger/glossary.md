# Glossary for `dkmedborger` (Danish, written natively)

Register: questions and explanations neutral and impersonal ("man", "en borger", "Hvad gælder
..."), like the real test; landing and dashboard copy in "du" (consumer-app norm, as dkindfoed).
Danish typography: » « for quoted titles and names (no straight double quotes), decimal comma,
thousands point, dates "4. maj", "1. maj til 30. september". No em-dashes or en-dashes. Never name
a current officeholder: ask about the office ("statsministeren", "monarken").
