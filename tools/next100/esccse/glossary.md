# Glossary for `esccse` (Spanish, written natively)

Register: questions and explanations in neutral third person, as in the Instituto Cervantes Manual; landing and UI copy in "tú" (as the other Spanish exams). Peninsular Spanish, «» not used in questions, numbers with a space for thousands (500 000) as in the Manual, decimal comma (0,5 g/l). No em-dashes.

| Spanish term (used) | English | Note |
|---|---|---|
| prueba CCSE | CCSE test | Conocimientos constitucionales y socioculturales de España |
| tarea | task / section | the test has five |
| APTO / NO APTO | pass / fail | |
| Cortes Generales | Parliament | Congreso de los Diputados + Senado |
| comunidad autónoma | autonomous community | 17, plus 2 ciudades autónomas |
| diputación | provincial council | cabildos in Canarias, consejos insulares in Baleares |
| empadronamiento | municipal registration | certificate from the ayuntamiento |
| TIE / NIE | foreigner identity card / number | |
