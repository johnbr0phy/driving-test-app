# Glossary for `fihunt` (Finnish, written natively)

Register: questions use "sinä" in scenarios ("Olet passissa ..."), otherwise neutral, like the
Metsästäjän opas; landing and UI copy in "sinä" (consumer-app norm). Finnish typography:
decimal comma (3,2 g), no-break space as thousands separator (2 700 J, 1 000 ha), dates
1.3.–19.8., °C, m, km. No em-dashes. Species are described in words, never by a picture.
