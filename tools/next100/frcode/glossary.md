# Glossary for `frcode` (French, written natively)

Register: questions and explanations use "vous", as the French code de la route is taught;
landing and dashboard copy use "tu" (consumer-app norm, like the German landing's "du").
French typography: decimal comma (0,5 g/l, 1,5 m), a space before units (50 km/h), « » for
quoted sign text, a no-break habit before ? and : is not enforced in the JSON. No em dashes.

Signs: always described in words (shape, colour, symbol), with the code of the arrêté du
24 novembre 1967 (AB1, AB6, B1...) only in explanations.
