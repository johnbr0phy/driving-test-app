## Outline and format

## Junos OS documentation used for facts (all fetched 2026-11-19)
- Junos OS Architecture Overview: Routing Engine builds routing tables and derives the forwarding table of active routes, copied to the Packet Forwarding Engine; PFE uses ASICs for Layer 2 and 3 lookups; control operations separated from forwarding. https://www.juniper.net/documentation/us/en/software/junos/junos-overview/topics/concept/junos-software-architecture.html
- Route Preferences Overview: lowest preference wins, range 0 to 4,294,967,295. https://www.juniper.net/documentation/us/en/software/junos/routing-overview/topics/concept/routing-protocols-route-preferences-overview.html
- Default route preference values table: direct 0, static 5, OSPF internal 10, IS-IS L1 internal 15, RIP 100, aggregate 130, OSPF external 150, BGP 170. https://www.juniper.net/documentation/en_US/junos12.2/topics/reference/general/routing-protocols-default-route-preference-values.html
- Junos Configuration Files Overview: 50 most recent committed configurations, juniper.conf.gz and juniper.conf.1.gz to .49.gz, rollback 0 newest, first three in /config and 4 to 49 in /var/db/config. https://www.juniper.net/documentation/us/en/software/junos/cli/topics/topic-map/junos-configuration-files-overview.html
- Commit the Configuration: commit, commit confirmed (10 minutes by default), commit at, commit comment, commit synchronize, show system commit, configure exclusive and private, candidate in /var/rundb/juniper.db. https://www.juniper.net/documentation/us/en/software/junos/cli/topics/topic-map/junos-configuration-commit.html
- Rescue Configuration: request system configuration rescue save, rollback rescue then commit, request system configuration rescue delete. https://www.juniper.net/documentation/us/en/software/junos/cli/topics/topic-map/junos-rescue-configuration.html
- Rescue and Recovery Configuration File: rescue.conf.gz in /config, load override, request system snapshot to /altroot and /altconfig, request system zeroize. https://www.juniper.net/documentation/us/en/software/junos/junos-install-upgrade/topics/topic-map/rescue-and-recovery-config-file.html
- Filtering Operational Command Output: compare, count, display set, display inheritance, except, find, hold, last, match, no-more, save, trim, refresh. https://www.juniper.net/documentation/us/en/software/junos/cli/topics/topic-map/filtering-operational-command.html
- Configuration Groups: apply-groups, first listed group takes priority, local values override inherited ones, apply-groups-except, wildcards in angle brackets, junos-defaults, display inheritance, re0 and re1 groups. https://www.juniper.net/documentation/us/en/software/junos/cli/topics/topic-map/configuration-groups-usage.html
- Login Classes Overview: predefined operator, read-only, super-user, unauthorized; cannot be modified; plain and -control permission forms. https://www.juniper.net/documentation/us/en/software/junos/user-access/topics/topic-map/junos-os-login-class-overview.html
- Router Interfaces Overview: type-fpc/pic/port naming, logical units, lo0 created automatically, fxp and em management interfaces, permanent and transient interfaces, families inet and inet6, show interfaces terse. https://www.juniper.net/documentation/us/en/software/junos/interfaces-fundamentals/topics/topic-map/router-interfaces-overview.html
- Default Routing Policies: BGP import accepts and export readvertises active BGP routes (IBGP rule); OSPF, IS-IS and RIP export reject everything; OSPF import accepts all OSPF routes and import policy acts only on external routes; direct and static accepted into inet.0. https://www.juniper.net/documentation/us/en/software/junos/routing-policy/topics/concept/policy-routing-policies-actions-defaults.html
- Firewall Filter Components: terms with from and then, all from conditions must match, families any, inet, inet6, mpls and others, terminating accept, discard, reject, nonterminating count, log, syslog with an implicit accept, next term, implicit discard of unmatched packets, one filter per family per direction. https://www.juniper.net/documentation/us/en/software/junos/routing-policy/topics/concept/firewall-filter-components.html
- Configuring Unicast RPF: strict and loose modes, strict by default, rpf-check under the inet or inet6 family, fail-filter, DHCP from 0.0.0.0, default route caution, not for core interfaces. https://www.juniper.net/documentation/us/en/software/junos/security-services/topics/topic-map/interfaces-configuring-unicast-rpf.html
- Route-Based Match Conditions for Routing Policies: match types exact, longer, orlonger, upto, prefix-length-range and through. https://www.juniper.net/documentation/us/en/software/junos/routing-policy/topics/concept/routing-policy-security-route-based-match-condition-understanding.html
- Static Route Preferences and Qualified Next Hops: lower preference used first, qualified-next-hop with its own preference for a backup path, no-readvertise, retain; passive rejects traffic for the route (so it is not used as a distractor). https://www.juniper.net/documentation/us/en/software/junos/static-routing/topics/topic-map/static-route-prefer-qualified-next-hop.html
- Recover a Root Password (search extract of the Junos user access guide, fetched 2026-11-19): console access required, not possible if the console is set insecure, single-user or recovery mode, set the root password and commit. https://www.juniper.net/documentation/us/en/software/junos/user-access/topics/topic-map/recovering-root-password.html

## Not used or left out
- The documentation disagrees on whether Junos falls back to the local password when a reachable RADIUS server rejects a login with `authentication-order [ radius password ]` (current user access guide versus older and subscriber guides), so that case is not asked; only the unreachable-server case is.
- No fees, exam prices or recertification credits. No item on MPLS, which the objectives do not list. Junos OS Evolved differences are left out (the exam is based on Junos OS 21.2).
- Simulations or drag-and-drop are not part of JN0-106 (multiple choice only); the bank's few order, matrix and typed number items are Tigertest practice formats.
