# Glossary for `nlbrom` (Dutch, written natively, Netherlands usage)

Register: questions, explanations, landing and dashboard copy all in "je" (the CBR's own site
speaks to moped candidates with "je", and the audience is 15 to 17). Netherlands Dutch, not
Belgian ("rijbewijs AM", "bebouwde kom", "trottoir" or "stoep", "toeteren"). Typography: decimal
comma (0,2 promille, 0,75 meter, 12,5 m), km/u, m; curly single quotes ‘ ’ for sign and plate
texts; no straight double quotes and no em-dashes. Signs are described in words (shape, colour,
symbol) with the BABW code where it helps, "rond blauw bord met een witte fiets (G11)".
