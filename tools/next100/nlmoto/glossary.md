# Glossary for `nlmoto` (Dutch, written natively)

Register: questions, explanations, landing and dashboard copy in "je", like the CBR's own pages
and examenplan. Dutch typography: ‘ ’ quotes inside stems, decimal comma (0,2 kW/kg, 0,2 promille),
thousands point (3.500 kg), km/u, m, cc, kW. No em-dashes. Signs are described in words (shape,
colour, symbol), without BABW codes in the stem.
