# Glossary for `plteoria` (Polish, written natively)

Register: questions and explanations address the candidate in the second person singular ("ty":
"musisz", "jedziesz", "czy wolno ci"), like Polish driving-school material, and avoid past-tense
and modal forms that mark gender ("powinieneś", "zatrzymałeś"). Landing and dashboard copy also
use "ty". Typography: „ ” quotes, decimal comma (0,5 ‰, 1,6 mm, 0,25 mg/dm³), km/h, m, t.
No em dashes and no spaced en dashes; ranges are written "30-50 m" or "od 150 do 300 m".

Signs: always by their official code from the signs regulation, "znak A-7 („ustąp
pierwszeństwa”)". Where a question asks what a sign means, only the shape, colour, symbol and code
are given, never the name.
