# Högskoleprovet: glossary (sv, UHR's own terms)

| Swedish (as UHR writes it) | English | Notes |
|---|---|---|
| högskoleprovet | the Swedish Scholastic Aptitude Test (SweSAT) | lower case in running text, as on studera.nu |
| UHR, Universitets- och högskolerådet | Swedish Council for Higher Education | sets the test; universities give it |
| provpass | test session (pass) | 40 uppgifter, 55 minuter |
| utprövningspass | try-out pass | unscored; candidates do not know which one |
| uppgift, uppgifter | item(s) | never "fråga" for a test item in UHR copy |
| delprov | subtest | ORD, LÄS, MEK, ELF, XYZ, KVA, NOG, DTK |
| verbal del | verbal part | ORD, LÄS, MEK, ELF |
| kvantitativ del | quantitative part | XYZ, KVA, NOG, DTK |
| ORD, ordförståelse | vocabulary | five alternatives |
| LÄS, svensk läsförståelse | Swedish reading comprehension | |
| MEK, meningskomplettering | sentence completion | gaps marked ___ here |
| ELF, engelsk läsförståelse | English reading comprehension | texts and questions in English |
| XYZ, matematisk problemlösning | mathematical problem solving | |
| KVA, kvantitativa jämförelser | quantitative comparisons | "Kvantitet I", "Kvantitet II"; four fixed alternatives |
| NOG, kvantitativa resonemang | data sufficiency (quantitative reasoning) | "Tillräcklig information för lösningen erhålls"; five fixed alternatives |
| DTK, diagram, tabeller och kartor | diagrams, tables and maps | |
| råpoäng | raw score | 0 to 160, 0 to 80 per part |
| normerad poäng, normering | normed score, norming | 0,00 to 2,00 in steps of 0,05 |
| högskoleprovsresultat | the overall result | mean of the two normed parts |
| facit | answer key | |
| provhäfte, svarshäfte | test booklet, answer sheet | |
| rekommenderad provtid | recommended time | per delprov |
| minuspoäng | penalty points | none on this test |
| urval, urvalsgrupp | admission selection (group) | |

Typography: decimal comma (0,5; inside KaTeX `0{,}5`), thousands with a space (12 000), "%" after a
space (25 %), times as 07.12, straight double quotes, no en or em dashes ("16 till 29 år", not
"16-29"). Register: items neutral; landing and dashboard copy in "du".
