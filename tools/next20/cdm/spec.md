# CDM build specification
id cdm; type CDM; prefix CDM-; idBase 34000; slug /cdm; landing /cdm-practice-test.
Four 50-question tests. Five domain training sets in outline order: Nutrition 40 (10/test), Foodservice 44 (11), Personnel & Communications 40 (10), Sanitation & Safety 48 (12), Business Operations 28 (7). The smaller final set is intentional: exact 14% blueprint weighting.
CBDM outline effective March 1, 2025: 20%,22%,20%,24%,14%. Practice threshold 70%, explicitly a study target: official cut score is set by CBDM, historically about 70%, not a fixed guaranteed official threshold.
Primary references: CBDM 2025 practice standards (17 PDFs), FDA2022 Food Code. Original scenarios and arithmetic, no sample/past questions or official question pools. Practice does not reproduce the160-item exam or promise exhaustive textbook coverage. Clinical questions stay within CDM screening/implementation duties; no independent diagnosis or prescribing.
Safety options must include timing/scope distractors; 'report' is not a universal key. Personnel items include applying existing procedures, auditing, analyzing work and direct coaching, not merely escalating.
