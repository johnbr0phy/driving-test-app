## Source allocation and authoring gate

- All domains: original Annex I (image pages read), consolidated order and current CMA format.
- T3P/REG: current targeted Code des transports and current orders; historical 2025 compilation is an index only. Parent-preserved fulltext retrieval of 2025 reservation order resolves that specific gap; read before writing REG.
- GES/COM: specific Bpifrance Création financial/marketing guidance, current Service Public and INPI/URSSAF/DGCCRF/CNIL guidance. INPI's comparison contains an outdated EI patrimony line: do not use that line. Service Public F23844 correctly describes automatic separation and exceptions. Specific fiscal/social details require their own source.
- SEC: current Code de la route targeted sections and government road-safety/first-aid guidance. ONISR general overview is not the authority for stale points.
- FRA/ANG: Annex I and original language texts; no external factual world knowledge needed to answer comprehension questions.

Before writing each category, create item-level objectives and map each factual rule to an actually read source. The table defines required breadth; it does not claim all source gaps have already been closed. Never use repeated versions of one rule to fill an uncovered objective.

## Distractor plan

No shared option sets or wording templates. For regulatory items, neighbouring valid duties must be wrong for the actor/location/timing at issue. For calculations, distractors reflect one identifiable operation error. For language items, distractors preserve most of the passage but change precisely one meaning-bearing feature. No answer may simply repeat a fully supplied decision criterion. Safety questions must include legitimate continue/proceed cases and distinguish correct timing, avoiding a bank-wide stop/report/decline cue. Unique options must be natural French and approximately similar length; do not pad for metrics.

## Post-authoring reconciliation

The item-level source map records the final 200 objectives, rather than claiming every example in the initial breadth list was selected. Self-review replaced an overlapping carpool question with paid intermediation, an exam-progression item with the employee driver's personal card requirement, and a repeated commercial complaint objective with mutual consent to change a firm contract (Civil Code article 1193). Each final objective has a read primary source, or an original language passage supported by the official language competency.
