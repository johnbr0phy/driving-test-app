# NSW Selective (`nswsel`, v2): wiring for shared files

Exam files already in place: `lib/v2/exams/nswsel.ts` (export `NSWSEL`),
`lib/v2/banks/nswsel.ts`, `data/v2/nswsel/questions.json` (258 items, 14 stimuli),
`app/nsw-selective/*` (six wrappers copied from `app/ged/`, fully free, no `V2TestGate`),
landing `app/nsw-selective-test-practice-test/page.tsx`.

Rebuild: `python3 -I tools/nswsel/maths.py && python3 -I tools/nswsel/build.py`
(sources: `tools/nswsel/reading.json`, `reading_stimuli.json`, `maths.py` -> `maths.json`,
`thinking.json`; edit the sources, never `data/v2/nswsel/questions.json`).

Validate: `python3 -I tools/validate_v2_bank.py nswsel '{"1":{"reading":{"1":38},"maths":{"1":35},"thinking":{"1":40}},"2":{"reading":{"1":38},"maths":{"1":35},"thinking":{"1":40}}}'`
(writes `nswsel: 258` into `lib/v2/bankSizes.ts`).
