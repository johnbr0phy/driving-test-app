# NSW OC test (`ocnsw`, v2): wiring for shared files

Exam files already in place: `lib/v2/exams/ocnsw.ts` (export `OCNSW`), `lib/v2/banks/ocnsw.ts`,
`data/v2/ocnsw/questions.json` (233 items, 14 stimuli), `app/oc-test/*` (six wrappers copied from
`app/nsw-selective/` / `app/ged/`, fully free, no `V2TestGate`), landing `app/oc-test-practice-test/page.tsx`.

Rebuild (edit the sources, never the built JSON):
`python3 -I tools/ocnsw/reading.py && python3 -I tools/ocnsw/maths.py && python3 -I tools/ocnsw/thinking.py && python3 -I tools/ocnsw/build.py`

Validate: `python3 -I tools/validate_v2_bank.py ocnsw '{"1":{"reading":{"1":33},"maths":{"1":35},"thinking":{"1":30}},"2":{"reading":{"1":33},"maths":{"1":35},"thinking":{"1":30}}}'`
(writes `ocnsw: 233` into `lib/v2/bankSizes.ts`).
